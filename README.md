# GreenUp

식품 바코드를 찍으면 친환경 제품 정보를 보여 주는 안드로이드 앱입니다. 2023년 7월부터 10월까지 팀 프로젝트로 만들었습니다.

## 기능

- 바코드 스캔으로 식품 찾기
- 이름으로 식품 검색, 제품 정보와 인증마크 보기
- 재활용 방법 글과 환경 이야기 글 모아 보기
- 로그인, 프로필, 알림 설정

## 기술

Kotlin, XML 레이아웃, Retrofit, Moshi, Room, Glide, ZXing

식품 정보는 식품안전나라 공공 API에서 가져옵니다.

## 실행

Android Studio로 열어서 실행합니다. minSdk 24입니다.
